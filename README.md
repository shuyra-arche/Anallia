# Anallia · 几何阅读演示

用圆与直线组织章节的阅读空间。演示包含圆周阅读、斜向线枢、长文、主题转场、星空与流场，以及实时搜索和阅读设置。

[在线体验](https://shuyra-arche.github.io/Anallia/)

建议路线：从首页进入圆周阅读 → 切换圆线形态 → 进入斜向线枢 → 阅读长文 → 选择背景。九标签和十二标签序列保留在进阶入口。

## 运行

要求 Node.js 22.18+。

```sh
npm ci
npm run dev
```

开发服务监听 `0.0.0.0:5173`；同网段设备可访问终端列出的 Network 地址。预览服务监听 `0.0.0.0:4173`。端口占用时退出，不会悄悄换端口；临时验证可通过 `npm run dev -- --port 5175` 显式指定其他端口。使用 IP 访问即可，保留 Vite 默认 Host 检查和自动热更新地址。

验证和生产构建：

```sh
npm test
npm run build
npm run preview
```

`dist/` 可部署到静态网站托管平台。

## 操作

- 点击正文链接进入子章节或其他枢；滚轮和方向键仅切换同层章节，只有一个标签时停留在当前层级。
- 点击当前标签或枢曲线切换圆／线形态，形变时保持聚焦材料点的屏幕位置和缩放比例。
- 触控抓住曲线或聚焦标签连续浏览章节，松手吸附；空白处拖动平移，双指捏合缩放。Alt/Ctrl/Command + 滚轮或 `+ / -` 也可缩放。
- 局部标签固定沿普通标签的后续方向展开，空间不足时局部滚动；普通标签的位置与间距不受局部标签数量影响。滚动切换普通标签时，旧的局部标签组翻页退场，再展开新聚焦标签的局部标签组；快速滚动只展开最后停留的一组。
- 长文上滚动或触控拖动会沿阅读方向浮动正文；桌面鼠标仍可选择、复制文字。局部标签带可独立滚动。
- `↑` 返回上一级；`↶ / Escape` 历史返回；`⊙ / Home` 进入全域；`⌕` 检索；`⚙` 设置。
- 切换枢会恢复适合阅读的默认倍率，并将正文列完整放入视口；进入后仍可手动缩放。
- 聚焦时全局操作位于当前枢曲线对侧；全域或缩放小于 0.45 时使用固定工具栏，`⌖` 回到当前焦点。
- 检索实时生成结果标签，结果可跳回原章节；返回历史同时恢复查询和结果。
- 设置提供景深、伴读、减缓动效、运动速率、帧率档位、背景及恢复默认确认层。恢复默认时遵循当前系统减缓动效偏好。
- ⚙ → ⚙₆「背景」可选流场、星空、关闭，选择保存在当前浏览器。星空包含色阶渐变星轨和偶发流星；随当前枢明暗调整配色，在正文附近淡出。开启减缓动效后保留静态星空。
- 操作图标使用选定的九个静态图形，圆／线切换不改变形状，悬停只变色；标签自身仍可翻页。
- 加载反馈由真实内容任务触发；首次内容可读后进入阅读，后续正文连续到达。可取消的前台请求可按 Escape 取消。

## 转场与布局

同枢同层切换使用 Traverse；层级内容替换在固定材料铰点执行 Page Flip；圆／线切换使用 Morph。跨枢根据显式父子关系和视口距离选择 Axis / Near / Flight / Remote。换色遮罩只在源枢与目标枢底色不同时出现；同底色只进行镜头转场，不折叠枢曲线。

镜头缩放统一作用于枢中心距离、曲线、标签、图标、正文和背景。顶部按钮和左下角说明文字保持固定屏幕大小。尺寸、描边与附着间距同比例变化，正文保持原有换行布局。顶部操作按钮无边框。正文按曲线外法向展开，左右与上下方位不由屏幕边缘反转。进入来向决定阅读姿态，圆态切换标签使用稳定的焦点支点，直接抓握保持圆心支点；线枢保留来向形成的倾角。阅读窗口保持正向并避开曲线，长文在窗口内浮动；自动取景在必要时平滑避让屏幕边缘，手动平移缩放后保留用户视野。详细规则见 [方向与阅读支点](docs/directional-reading.md)。v6 规则见 [语义附着模型](docs/attachment-model-v6.md)，局部导航见 [局部导航与缩放](docs/interaction-grammar-v5.md)，其中固定屏幕尺寸的旧规则已被统一缩放替代，转场规则见 [转场语法](docs/transition-grammar-v3.md)。v4 和更早文档用于记录此前方案，与当前实现冲突时以当前代码和上述文档为准。

## 修改入口

- 内容、枢定义及显式父子关系：`src/content/author/`（生成清单与搜索索引；`src/content/field.ts` 为旧测试兼容出口）；保持章节 ID 稳定，链接使用 `{显示文字|章节ID}`。
- 配色和排版：`src/styles.css`。
- 几何和投影：`src/geometry/`。
- 附着规划：`src/application/attachments.ts`；静态图标：`src/core/icons.ts`。
- 正文构建：`src/rendering/article.ts`；场景更新：`src/rendering/scene.ts`。
- 模块边界：[architecture.md](docs/architecture.md)；本次来源、修正与验证：[gemini-merge.md](docs/gemini-merge.md)。

正文由文本节点和按钮构建。目录检查重复 ID、无效引用、父子环和不连通章节；查询结果保存在各自阅读会话中。

## GitHub Pages

`.github/workflows/pages.yml` 在推送到 `main` 时运行测试、构建并发布，也支持手动运行。仓库 Pages 的构建来源为 GitHub Actions。

```sh
npm run build:pages
```

该构建使用 `/Anallia/` 作为资源根路径，发布 `dist/`。本地开发与普通构建继续使用站点根路径。

演示主线与进阶内容见 [演示路线](docs/demo-route.md)。

## 独立演示

从当前源码生成模块预览和单文件网页：

```sh
node tools/build-preview.mjs
node tools/build-single-html.mjs
```

`preview/` 需通过本地静态文件服务访问；`demo.html` 可直接在浏览器打开。两者与 `dist/` 一样是生成产物，修改源码后需重新生成。导出使用 Vite 打包，包含 PixiJS、Pretext 和按枢拆分的本地正文；单文件导出合并所有模块，支持离线打开。

仅开发服务器提供 `/dev/loading.html` 几何预览。正式页面不包含独立加载舞台或播放入口。

## 验证边界

当前重构按检查点记录在 [重构验收记录](docs/refactor-status.md)。最近数值 SVG 后端整合通过类型检查和 200 项单元测试；真实浏览器回归与性能指标分别记录，不以功能测试通过代替性能验收。第二台局域网设备、真实移动端及硬件 GPU 仍待验收。

本机检查使用进程组内存和超时硬限制；`npm test` 为 1GiB / 120s、浏览器为 3GiB / 110s 且单工作者。需要 Linux 用户 systemd 会话，缺少限制能力时拒绝启动。CI 在独立运行器中串行执行有堆限制和逐项超时的测试。

端口和 Host 行为可在构建后执行 `node tools/server-test.mjs` 检查，需要默认端口空闲；它只停止自己启动的服务器。性能记录通过 `SHUYRA_PERF=1 npm run test:browser -- --grep=100000-character` 显式启用，原始 JSON 写入 test-results；功能断言通过不表示 P95 性能目标达标。

`renderer=auto` 默认尝试 WebGL；识别到软件渲染器时保持 SVG，避免软件 GPU 的明显掉帧。`renderer=gpu` 可强制对照，`renderer=svg` 可固定回退。未知设备信息不触发软件判定。
