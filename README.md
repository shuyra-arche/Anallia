# Shuyra · Field

以 Field 026 蓝图为基础的几何阅读网站。保留 α、β、θ 与设置枢的演示内容，支持圆／线切换、递归阅读、跨枢引用、全域视图、主题扫掠、文字景深、流场与波动扰动，以及原 V24 加载动效。

## 运行

要求 Node.js 22.18+（测试使用 Node 内建 TypeScript 支持）。

```sh
npm ci
npm run dev
```

打开终端打印的本地地址。生产版本：

```sh
npm test
npm run build
npm run preview
```

`dist/` 可部署到支持静态文件的网站托管平台。

## 操作

- 正文中的链接：进入子章节或跳转到其他枢。
- ⌕：进入检索枢，输入关键词后实时生成结果标签；结果正文可跳回原章节。
- 正文可选择、复制，支持多段长文和横向／纵向列表。长文超出画面时，在正文上滚动会移动阅读视野，不切换章节。
- 当前标签或枢曲线：切换圆／线形态。
- 滚轮、上下方向键：切换同层章节。
- 拖动：移动视野；全域滚轮、Alt/Ctrl/Command + 滚轮、双指捏合：缩放。
- ↑：上一级；↶ / Escape：返回；⊙ / Home：全域；⚙：设置；◌：加载动效。
- 聚焦状态下可缩放；`+ / -` 也可缩放。圆态滚动时圆心的屏幕位置固定，保留用户缩放比例；线态镜头沿轴移动。
- ⚙ → ⚙₅：景深、伴读、减缓动效开关，以及恢复默认设置的确认层。
- ⚙ → ⚙₄「帧率与显示」：省电自适应、30 / 60 / 90 / 120 FPS、跟随屏幕刷新率。所选档位保存在当前浏览器。
- 加载动效中点击或按 Escape / 空格：结束并离场。

## 修改入口

- 内容和枢定义：`src/content/field.ts`。保持章节 ID 稳定，链接使用 `{显示文字|章节ID}`。
- 配色、字体、排版：`src/styles.css`。
- 几何模型：`src/geometry/field.ts`。
- 模块职责与依赖：`docs/architecture.md`。

正文按文本节点和按钮生成，不将内容直接注入 HTML。内容加载时检查重复 ID、无效引用、父子环和不连通的章节。

## 验证边界

测试覆盖纯几何、导航状态、场景 DOM 和加载动效生命周期；构建执行严格 TypeScript 检查。DOM 模拟不测量真实字体、模糊开销、手机手势或浏览器帧率，正式视觉验收仍需在浏览器进行。

原蓝图的 V24 绘图内核保留为独立 JavaScript 模块，入口带类型注释；其余逻辑采用严格 TypeScript。它不读取阅读状态，只持有自己的 SVG 子树和动画进度。
