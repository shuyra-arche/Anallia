## 合入功能

- 检索枢、实时结果标签和返回原章节的引用。
- 多段长文、横向／纵向列表、文字选择与复制。

## 审查后修正

- 原版搜索命令会取消任何枢的镜头运动，且能在过场期间执行；现在仅在检索枢可交互时接受输入。
- 检索结果从可变内容目录移至阅读会话状态，返回快照恢复查询和结果，避免返回后选中项不在当前结果中。
- 把具体检索枢 ID 从几何算法中移除，改用显式角色和布局数据。
- 将富文本构建拆出场景渲染模块，保留 DOM、导航和内容边界。
- 原版长文可能超出裁剪视口且滚轮无效；现在长文上的滚轮可移动阅读视野，同时保持章节与文字选择。
- 恢复默认设置尊重当前系统减缓动效偏好。
- 中文组合输入结束后的重复 input 事件不再重复提交查询；重绘保持输入节点、焦点和光标。
- 设置选项改变文字尺寸时清理测量缓存。
- 修正部分演示文案中与实际算法不符的描述。
