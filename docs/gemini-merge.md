# Gemini 修改审查与合并

来源：用户提供的 `field.zip`，2026-10-27。

SHA-256：`b980e0937bfb9f86e9aef00c125aa8e39472245f60b3e11b9bb4802aaf87dee7`

## 合入功能

- 检索枢、实时结果标签和返回原章节的引用。
- 多段长文、横向／纵向列表、文字选择与复制。
- 景深、伴读、减缓动效开关，以及恢复默认设置的枢内确认层。
- 等弧长章节和导航标签布局、多节点可见窗口。

## 审查后修正

- 原版搜索命令会取消任何枢的镜头运动，且能在过场期间执行；现在仅在检索枢可交互时接受输入。
- 检索结果从可变内容目录移至阅读会话状态，返回快照恢复查询和结果，避免返回后选中项不在当前结果中。
- 把具体检索枢 ID 从几何算法中移除，改用显式角色和布局数据。
- 将富文本构建拆出场景渲染模块，保留 DOM、导航和内容边界。
- 原版长文可能超出裁剪视口且滚轮无效；现在长文上的滚轮可移动阅读视野，同时保持章节与文字选择。
- 恢复默认设置尊重当前系统减缓动效偏好。
- 中文组合输入结束后的重复 input 事件不再重复提交查询；重绘保持输入节点、焦点和光标。
- 设置选项改变文字尺寸时清理测量缓存。
- 修正部分演示文案中与实际算法不符的描述。

## 验证

- 严格 TypeScript 检查、36 项 Node / DOM 模拟测试和生产构建通过。
- 保留静态零 DOM 改动、背景工作预算、圆心投影固定和高刷新率调度检查。
- 压缩包中的 dist 未直接合入，使用最终源码重新生成构建产物。
- 中文输入事件、小屏长文和排版状态由 DOM 模拟验证，尚未进行真实浏览器的完整视觉与性能验收。
