按用户选择，正常入口、无效参数及 Scene API 的缺省值恢复为 auto：优先 WebGL，初始化失败、上下文丢失或明确软件设备时在本会话回退 SVG。保留显式 gpu / svg 参数，`9fd6652` 的屏外虚线优化不变；以下性能和完整回归数据仍对应各自检查点。 本次默认值调整通过类型检查、16 项渲染单元测试、2 项可见浏览器定向回归及普通构建；未重复性能压测及其他导出构建。

## 屏外虚线优化检查点（9fd6652）

- 正式入口和 Scene API 默认使用 SVG；参数无效同样使用 SVG。保留显式 `renderer=gpu` / `renderer=auto`，后者仍识别软件设备并永久回退。

- Scene 与 Pixi 新增可关闭的互斥分段采样；正常运行不采样，性能测试分别记录完整更新、缓存帧、阶段占比及慢帧明细。每帧各阶段之和由测试核对，不把多个 P95 相加。
- 类型检查、256 项单元测试、2 项分段计时浏览器用例与 3 项原交互定向回归通过。两项可见浏览器性能检查实际使用 RTX 5070 Ti，完整接收十万字、阅读漂移 0px；普通构建通过。本增强没有重跑全部 33 项行为检查及另三种导出形式。

- 本次 SVG / GPU 路线 rAF 间隔 P95 为 5.4 / 16.7ms，流式提交 3.1 / 3.2ms，两者达到本次目标；此前用户测得的帧间隔次序不同，不能认定固定两倍加速。原始数据、源快照和统计口径见 [性能记录](performance.md)。
