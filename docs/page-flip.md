# Shuyra Field — 附着式翻页转场（v2）

## 目标

枢的圆态与直态是**同一材料曲线**的两种表达，其本体变换仍由 `transformLocal()` 中的 Möbius 公式完成。标签和正文均附着在同一曲线的**语义点** `material(hub, s)` 上，不能各自使用屏幕空间的虚拟 pivot。

翻页是另一个可叠加层：相当于书页以枢上的点为装订轴，围绕该点做一整圈旋转。旧内容从正面旋开，在背面不可见阶段替换语义表现，再由新内容旋回正面。翻页不会修改曲线或节点的身份。

## 物理/状态规则

- `FieldState.morphTurn`：圆↔线状态切换的唯一 840ms（可变速）进度时钟。`hub.morph = mix(from, to, ease(phase))`，与 camera tween 同步；旧版的非定长形变指数逼近不再用于交互式 morph。
- `pageTurnPose(phase)`：负责标签/正文共同的转动角、投影宽度、透明度、是否已经切换为新表达，以及交互锁定。角度 = ±360° × smoothstep(phase)。
- 0%：旧内容可阅读，枢姿态处于起点。
- 约 30%：旧内容逐渐侧立退场（90°）。
- 50%：处于背面（180°），**不显示镜像文字**；表达从圆版切到直版，或源内容从此时起切到目标内容。
- 约 70%：新内容从背面回到正面（270°），逐渐可读。
- 100%：新内容与枢的目标形态稳定（360° ≡ 0°）。
- 反向时角度为 −360°，源与目标内容顺序相反。
- `prefers-reduced-motion`：不展示翻转，状态直接结算。

## 锚点和渲染

1. `s = nodeS(hub,index,...)` 只决定语义位置；`material(hub,s)` 唯一计算真实几何附着点。
2. SVG 标签：外层 `<g>` 放在该点；固定金色小销钉不参与翻转；内层 `page-leaf` 围绕它旋转。SVG 用沿外法线方向的正交压缩模拟 3D 书页投影，且隐藏背面。
3. HTML 正文：同一个附着点作为 `translate3d` 的起点，`transform-origin:0 0`；随后 `rotateZ(法线方向) rotateY(翻页角)`，最后才向外平移到阅读位置。让位移发生在旋转之后，保证书页枢点不会跟随屏幕偏移漂移。
4. 文本尺寸不乘相机 `zoom`，其阅读区与变换的锚点解耦。
5. 书页翻动期间关闭正文及标签命中；结算后恢复。长文浮动仍以锚点为阅读基准。

## 可叠加使用

- **Morph**：同一枢的 Möbius 曲线形变 + 标签翻页 + 正文翻页同步进行。
- **Unfold/Fold/Passage**：保留 v1 对应的父子及跨枢镜头/几何过场；同时源标签/正文翻出，目标标签/正文翻入。中点在隐藏状态下提交目标语义。
- **Traverse**：同枢章节移动仍使用原来的圆态旋转、直态平移；避免短距离滚动时反复翻书。
- **Loading**：保持独立 V24 生命周期，不加入翻页。

## 仍未覆盖

- 距离感知的 Near/Flight/远距 Möbius 路由尚未在本版替换 v1 的跨枢 Passage。
- 父子枢的圆柱轴旋转仍是独立的几何/相机动效议题；本版仅保证它们的标签和正文能使用相同的翻页层。
- 跨枢时，源与目标锚点属于不同局部材料坐标；在不可见的 180° 背面阶段完成语义切换，而不是假装两个位置具有同一个世界坐标。
- 先前版本的移动端正文越界属于独立布局问题，不是翻页层的几何漂移，尚未在本版解决。
