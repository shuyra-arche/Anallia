# Shuyra Field v4 — 空间交互与阅读布局

## 总原则

**变化的语义决定转场，几何锚点决定位置，屏幕空间决定可读朝向。**

转场仍是三条互不强制绑定的时钟：`contentTurn`（同锚点翻页）、`morphTurn`（圆↔直 Möbius）和 `passage`（跨枢空间导航）。

## 本版修改

1. **圆直转换镜头跟随**：进入 Morph 时记录当前正文语义材料点的屏幕像素位置。每一帧根据当前 Möbius 曲线和外法向重新求解摄像机平移、旋转，严格保持该点的屏幕投影；保留现有缩放比例。源和目标用同一算法，支持反向。Morph 不自动启动翻页。
2. **触控抓握**：手指按住当前枢曲线或聚焦标签再拖动，圆态按手指绕圆心的有符号角度推进章节，直态按沿枢轴切线的位移推进章节；章节进度连续变化，松开后吸附最近语义节点。抓握不触发 Morph、Passage 或 Page Flip；双指仍可缩放，正文区域仍用于文字阅读/滚动。
3. **导航分层**：全局导航 `⊙ ⌕ ↶ ⚙` 独立于枢曲线、固定于屏幕边缘；全域下有情境 `⌖`。局部 `↑` 和当前章节的引用标签，以聚焦标签为起点向下列队，在屏幕下方不足时向上列队。兄弟章节标签仍属于枢曲线。
4. **自适应展开方向**：正文与聚焦标签根据实际安全区域选择向左/向右展示；窄屏无法容纳侧栏时，正文在锚点附近采用上下堆叠。靠近屏幕底部优先向上展开。方向决策带滞回，防止经过屏幕中央时抖动；反向时内容布局 240ms 平滑调整，锚点仍沿真实枢材料曲线移动，文字不镜像。
5. **窄屏保障**：阅读正文实际宽度由视口可用面积确定，不再让初始内容超出 320/390px 手机屏幕；SVG 标签与触控命中目标不再被相机缩小到极小尺寸。

## 完整转场矩阵（延续 v3）

| 情况 | 转场 | 镜头 / 枢 / 内容 |
|---|---|---|
| ⚙₀→⚙₁、同一语义锚点内容替换 | Page Flip | 镜头、枢不动，书页绕原锚点转 |
| 圆态↔直态 | Möbius Morph | 枢本体连续变形，镜头围绕聚焦锚点动态补偿；不翻页 |
| 同枢相邻章节 | Traverse | 圆态沿弧、直态沿轴；不翻页 |
| 触控抓握同枢章节 | Scrub → Snap | 手指直接控制连续章节坐标，松开吸附；不翻页 |
| 明确父子枢关系 | Axis Rotation | 2.5D 镜头姿态表现层级；保留 v3 机制 |
| 近距跨枢 | Near | 直接移动 |
| 中距跨枢 | Flight | 拉远—平移—聚焦 |
| 远距跨枢 | Remote Möbius | 空间折叠；仅此时使用跨枢门户遮罩 |
| 全域/归焦 | Overview/Focus | 镜头运动，枢几何不变 |

只有内容真实替换时才使用翻页；布局反向不翻页，触控抓握不触发 Möbius。若同一操作同时修改形态与内容，可明确请求两种机制叠加，但不得隐式捆绑。

## 操作和回归检查

- 桌面：点击聚焦标签切换圆/直；滚轮与方向键切换同层节点；在正文内滚动阅读长文；点击 `⚙` 后进子设置只翻页。
- 触摸：**单指按住曲线/聚焦标签并拖动**直接浏览，放手吸附；正文滑动保持阅读语义，双指捏合保持缩放。空白区域拖动平移镜头。
- 窄屏：对 320px / 390px 视口检测正文 `getBoundingClientRect()`，确保水平方向在安全边距内；将枢平移到屏幕左右侧，检查布局方向的滞回和反转。
- 圆/直：转场任意进度 `worldToScreen(material(...))` 必须保持进入转场瞬间的聚焦锚点屏幕坐标，且镜头 zoom 不变。

## 验证边界

本版有 Node 纯状态/几何测试与 Playwright Chromium 的桌面和手机宽度截图检查，也验证了设置只翻页、圆直切换和模拟触控的抓握行为。平台/设备不同仍可能存在实际手势差异：**未在真实 Android/iOS 触控硬件上逐设备验收，也未完成需要 `happy-dom` 的原有 DOM 单测（离线依赖未缓存）**。真正的父子枢需在内容里添加 `parentHub` 关系才能触发 Axis Rotation。
