# 几何阅读：平面圆枢逐行阅读

阅读排版由枢的 `readingLayoutMode` 属性声明：`window | geometric`，未声明时默认
`window`。它与内容的 `Presentation = circle | line` 独立。同一枢内的章节共享排版，
不同枢可使用不同排版；导航和历史返回保留各枢当前属性。

页面没有排版切换控件，也不读取或写入全局浏览器排版偏好。
内部 `set-reading-layout` 命令显式携带枢 ID；运行时编辑仅在当前会话有效，
刷新后按枢定义初始化。全局设置复位不修改枢的排版属性。

## 圆态

文字行围绕同一个平面圆枢排列，每行是一段完整的 DOM 文字，基线沿局部径向。
`geometry/circular-reading.ts` 按文字靠近枢一端约 22px 的行距安排圆周，一圈约 77 行；
短文保留同样的紧凑间距，不为铺满整圈而拉大间隔。长文按相同间距沿整圈接续。没有高度维度，
也没有向外扩张。未读行铺满圆周，当前位置最清晰，远处行减弱；读过的行淡出，
后续内容依次补入。来源行序号始终连续，不会因转过一圈而重新读旧文字。

正文区域内的普通滚轮推进正文：100px 滚轮量对应一行；触控复用 float-text 输入。
空白处及普通标签上的滚轮保持章节/标签切换，局部标签带继续独立滚动。
阅读滚动以枢圆心和当前注视行为参照，绕枢圆心旋转，让下一行到达当前注视行的
屏幕位置。圆心在屏幕上保持稳定，不重新平移到预设位置。相机坐标因绕枢的运动
自然补偿，屏幕中的圆心和阅读支点不跳动。

Alt＋滚轮是独立的自由观察，只改变相机朝向，不推进正文；自由旋转后再次阅读，
以当时的注视方向继续逐行推进，不强行复位到原朝向。方向键、引用和标签继续导航。
进入几何枢时的取景由 frameFor 负责，取景和正文滚动分开；可以手动平移和缩放，
缩小后查看整圈。铺满圆周不代表所有文字在当前放大倍率下都同时位于视口内。

## 线态与渲染

线态仍为水平文字行，枢和镜头倾斜只影响锚点，不旋转文字基线。
`geometry/geometric-reading.ts` 的静态几何接口继续可独立测试。

`rendering/geometric-article.ts` 使用 Pretext 的 prepareWithSegments / layoutWithLines
获取真实断行，将 segment/grapheme 游标换算成 UTF-16 来源位置。稳定块按字体、
列宽和字体版本缓存；几何姿态变化不重新测量正文。当前显示窗口中未变化的文字行
保留 DOM 节点，引用继续走现有按钮事件和语义反馈路径。

ReadingLayer 复用原 ArticleRenderer，同一 DOM 阅读层服务 SVG / WebGL。
标题使用 16px、正文使用 14px，并随镜头倍率缩放；演示页脚区域由裁剪保护。
标准窗口与几何阅读之间通过来源位置恢复进度，恢复受首尾边界限制。

## 限制与验证

列表、图标、搜索表单和搜索结果镜像保留标准窗口；Pretext 无法处理的文本亦回退。
线态不合适的角度或空间约束也继续使用标准窗口。跨窗口的长距离连续选择、任意
自定义排印、圆线转场的全部视觉连续性及长文性能基准尚未全面验收。

单元测试覆盖平面恒定半径、长文绝对行序号、透明度连续变化、阅读方向、圆心与当前注视行的屏幕位置
保持稳定、来源范围与缓存、枢属性独立性。浏览器覆盖 SVG / GPU 下的真实滚轮、
逐行旋转、旧行移除、新行显现、引用、选择和线态水平基线；标准阅读回归同时运行。
