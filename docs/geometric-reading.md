# 几何阅读：实验集成

右上角的「排版」可切换标准 / 几何（实验）。默认仍为 `window`；
`ReadingLayoutMode = window | geometric` 与 `Presentation = circle | line` 独立。
命令 `set-reading-layout` 经 Field 更新设置，浏览器偏好存储负责持久化。
导航和历史返回不重置排版设置；恢复默认设置会回到标准模式。

## 实现边界

`geometry/geometric-reading.ts` 计算屏幕空间的逐行基线中心、角度与可用宽度。
圆态基线沿投影后的局部径向；线态固定为 0°，枢和镜头倾斜只影响锚点。
材料坐标、曲线弧长及投影复用现有 geometry 接口。静态文字映射接口仍可独立调用。

`rendering/geometric-article.ts` 使用 Pretext 的 prepareWithSegments / layoutWithLines
获取真实断行，将 segment/grapheme 游标换算成 UTF-16 来源位置。标题、普通段落
和内联引用由 DOM 行承载，引用继续走现有按钮事件及语义反馈路径；未知目标保持文字。
稳定 ContentBlock 的断行按字体、列宽和字体版本缓存，几何姿态变化不重新测量正文。
显示的行内容不变时保留 DOM 节点；变化时按来源范围尝试恢复当前可见文字的选择。

ReadingLayer 复用原 ArticleRenderer 同步内容，通过独立几何分支摆放行。
几何行按固定列宽断行，视口内可容纳的连续行形成一个阅读页；滚轮和触控复用
原 float-text 命令，逐行推进。屏外行不会被永久删除，可通过滚动读到。
几何排版使用 14px 正文、16px 标题，镜头倍率同时缩放文字和行间距。
字号/样式的任意自定义及按每行可用宽度重新断行尚不支持。

模式切换通过来源位置连接标准窗口与几何页；字体版本和列宽变化也按首个可见
正文来源位置恢复。恢复位置会受页首、页尾与可容纳行数限制，不保证逐像素相同。
原窗口及其排版缓存保留，SVG / WebGL 共用同一 DOM 几何文字分支。

## 回退与限制

列表、图标、搜索表单、搜索结果镜像使用标准窗口，保留全部原交互。
当首行无法完整放入视口、直线接近水平而水平文字行无法分开，或 Pretext 无法
处理文本时，也整篇回退标准窗口。当前选项仍保持几何；界面会提示本次使用标准排版。
窄屏或手动平移可能触发回退，视角重新可用后恢复几何显示。

当前是可用的实验集成，不是完整 V1：没有任意倾角/字形的碰撞求解，也未解决
角度归一化跨越竖直方向或斜线变形终点的方向跳变。几何长文采用逐行翻动，
跨出当前可见页的连续文字选择及跨模式选择范围恢复不作保证。
尚无长文性能对比、流式压力基准、全部内容类型与动画过程的视觉验收。

## 验证

单元测试覆盖静态几何、斜线水平基线、来源范围、缓存失效、模式独立性与偏好容错。
浏览器测试覆盖 SVG 和 GPU 两个入口的实际断行、DOM 复用、选择、引用点击、
线态角度、滚动、字体失效、模式切换与复杂内容回退，并保留圆态截图。
原标准模式的桌面 DPR 2 / 移动模拟 DPR 3 阅读稳定性测试一同运行。
