# 加载使用规范

加载反馈只能由真实任务驱动。普通导航、翻页和圆线变形不创建等待任务。

- 首屏等待图形后端与首批正文排版；未缓存章节等待目标首批内容，保留当前正文。
- 刷新保留旧内容及阅读位置；后续流使用局部标识；后台预取不展示反馈。
- 150ms 后才显示；首次可读与流结束分别提交一次。完成从当前姿态退场，最长 200ms，不要求完整循环。失败和取消不作为成功。
- 保留三圆相切关系和主变换公式；使用所在枢的主题、材料锚点和方向，不切换到独立舞台。
- 未知进度不显示百分比；失败保留可读内容并提供重试；取消或旧请求不得提交迟到结果。
- 减缓动效使用静态姿态与短过渡，不能四分之一速延长等待。
- 正式界面不提供播放加载入口；开发预览可注入延迟、错误和测试源。

任务触发使用宿主的单调时间，不能借用上一帧时间缩短 150ms 门限。首次可读是幂等屏障，后续包只更新持续接收阶段；最终完成单独提交一次，不用动画周期推断完成。
