# Shuyra Field — Transition Grammar (v1)

空间关系决定转场类别，几何推导运动轨迹，阅读焦点决定显现顺序。

| 关系 | 类别 | 动作 | 参考时长 |
|---|---|---|---|
| 同级 | Traverse | 保持圆态绕中心 / 线态沿轴的原有运动 | 指数趋近 τ=190ms |
| 同一节点圆↔线 | Morph | Möbius 连续形变；表达内容在中点不可见时切换 | 镜头 840ms，形变 τ=190ms |
| 父→子（严格祖先） | Unfold | 结构展开；在阅读消隐后提交子节点 | 960ms |
| 子→父（严格祖先） | Fold | 结构沿逆向层级关系收拢；恢复父节点 | 960ms |
| 跨枢 / 跨分支 | Passage | 单一插值材料坐标系上的连续门户扫掠 | 1080ms |
| 全域→阅读 / 阅读→全域 | Focus | 镜头飞行；不伪造层级边界 | 820ms |
| 文字显隐 | Reveal | 0% 可读→46% 消隐→54% 后显现→100% 可读 | 随父转场进度 |
| Loading | Loading | 保留 V24 完整独立动画生命周期 | 1180ms 入场 |

## 反向规则

- 返回由目标历史快照的路径与当前路径重新判定转场类型；不是总播放 Passage。
- 对跨枢返回，Portal 的材料坐标系从新枢连续插值回旧枢，端点与前进相反。
- 对父子返回，进入为 Unfold，返回为 Fold；中点先隐藏原文，再恢复目标章节。
- 不强制在转场终点前提前更改章节语义身份；递归路径在 50% 的遮蔽窗口提交。

## 几何与颜色

- 过去的 `phase < 0.5 ? sourceHub : targetHub` 会导致边界在中点更换参考系。
- `passageGeometry` 现在对中心、最短角度和形态连续插值，以 `fold = smooth(2t)` / `smooth(2-2t)` 计算广义圆，沿用既有 Möbius 几何与 SVG 裁剪。
- 主背景在转场后半程逐步混合至目标主题；结构扫掠着色由 Portal 裁剪控制。
- 矿青标识结构连续性，黄铜标识导航与门户边界；深浅两主题遵循相同语义。

## 中断 / 连续操作

- 当前策略为 **Latest Intent Buffer**：转场中普通导航动作不丢弃，但不会中途把两个路径树同时重写；只保留最后意图，在转场完成时重新求值并执行。
- 连续 step 合并增量；快速选择其他节点则新选择替代之前的待处理命令。
- 输入队列的作用是避免失联，而不是即时物理打断。若后续需要即时可逆物理中断，应另行实现速度连续的进度反演及半程提交回滚。
- 搜索输入保持即时；文本移动和相机拖拽在门户转场期间被抑制，避免冲突。

## 缓动和无障碍

- 所有定长转场使用系统速度倍率；`prefers-reduced-motion` 或设置中的减少动态模式将定长时长压至一个逻辑帧。
- 表达切换时文字在 `morph≈0.5` 对称收敛为透明，避免圆/线版本内容在可见状态下跳换。
- 标签在 Passage 中与正文共享消隐窗口，且禁止不可见标签的命中。

## 回归点

1. A 根节点→a21：Unfold；返回：Fold；状态恢复。
2. A→B：Passage；返回：Passage(reverse)，中心、形态、方向端点相反。
3. 同级滚动：Traverse 不额外切换上下文、不改变相机缩放。
4. 连续点击：最后意图执行；历史快照不被中途破坏。
5. 两种主题/不同视口/简化动态：无 NaN/Infinity；Portal 中点边界没有源/目标硬切换。
6. 渲染器、移动端手势、视觉细节仍需目标浏览器目视验收；自动化几何和应用测试不能代替视觉检查。

## v2 附着式翻页覆盖规则

本文件前面的 `Morph` / `Reveal` 描述是 v1 的历史规则。自 v2 起，以 [page-flip.md](page-flip.md) 为准：`Morph` 由 840ms 显式 `morphTurn` 驱动，不再由指数趋近和 `morphReadingEnvelope` 定时；正文和标签围绕各自的**材料锚点**完成完整 360° 翻页。父子 / 跨枢 Passage 也叠加同一内容翻页，且返回反向。Loading 与同级滚动不翻页。
