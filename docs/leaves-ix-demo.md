# 叶之屋 · IX / 迷宫

本地启动后打开 `/?demo=leaves-ix`。也可使用
`/?demo=leaves-ix&chapter=ix-void` 直接进入空室；原有 renderer / morph 参数仍可用。
项目站点部署时沿用 `/Anallia/?demo=leaves-ix`，本次没有发布线上版本。

这是以《叶之屋》第九章的迷宫式排版为启发的原创文字习作，不包含该章正文，
也不复刻具体书页。蓝色空窗、镜像边字、朱色删线与偏离正文的边注构成视觉线索；
语义结构通过可导航的引用关系表达。这里使用的注释编号属于演示，不对应原作脚注。

## 阅读路线

- 正文：门槛 → 折角 → 回声 → 出口 → 门槛。
- 支路：注释 01 → 注释 02 → 空室 → 门槛。
- 底部目录允许直接跳转；「原路返回」消费现有导航历史。
- 「转动纸面」仅改变镜头朝向，保留 x、y 坐标，过场期间禁用。线态文字基线始终水平。
- 正文内滚动逐行阅读；空白处滚动切换同级标签，围绕枢中心将下一行送到当前注视位置，前文消隐、后文显现；蓝色空窗可点击进入空室。
- 排版由枢自身声明，页面没有排版切换入口；「离开习作」返回普通 Anallia 入口。

## 模块与范围

`src/demos/leaves-ix-content.ts` 扩展现有内容清单与 ContentSource：七个原创阅读位置，
分布在三个枢中。原清单不被修改，普通章节继续委派原内容源，搜索和设置保持可用。
新增内容不写入通用 author / generated 数据，演示通过显式 URL 参数按需加载。

`src/demos/leaves-ix.ts` 仅增加导航、边注、空窗和访问痕迹，正文仍经过原有
ReadingSession → ReadingLayer → Pretext / DOM 路径。版式样式限定在演示根属性下；
退出后恢复普通页面。演示默认无动态背景、静音；三个演示枢分别声明几何排版，普通枢仍保持自身属性。
所有演示内设置不写回偏好。

正文按整圈排布，短文保留紧凑行距，长文以可读容量接续。几何行裁剪保护页脚，避免正文覆盖路径导航。
窄屏沿用标准窗口回退，隐藏边栏和空窗，保留可操作的路径导航。
因此这不是原书纸面版式的完整数字复刻：列表、连续镜像正文、逐页穿孔以及全章阅读
仍不在本轮范围内；现有几何阅读的动画连续性和长篇选择限制也仍然存在。

## 参考与验证

设计参考的是迷宫式层级与脚注支路的阅读形式：
[Reading Today](https://discovery.ucl.ac.uk/10041155/1/Reading-Today.pdf)、
[The Many Storeys of the House of Leaves](https://starless.wordpress.com/2009/12/08/the-many-storeys-of-the-house-of-leaves/)。
正文全部独立编写。

单元测试验证清单隔离、全部引用目标、两种内容表达、委派和取消。
浏览器测试覆盖 SVG / GPU、正文与注释分叉、历史返回、斜线水平基线、实际相机旋转、
偏好隔离和移动端退出；截图由浏览器测试生成，并人工检查圆态、线态和移动版。
普通几何阅读及桌面/移动标准阅读回归一同运行。
