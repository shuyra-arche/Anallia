# 模块边界

`main.ts` 是组合入口，负责创建模块、注入依赖、启动和释放生命周期。其他模块不引用它。

| 模块        | 职责                                  | 依赖边界                                                     |
| ----------- | ------------------------------------- | ------------------------------------------------------------ |
| core        | 类型、向量和缓动数学                  | 无页面、内容或运行时依赖                                     |
| content     | 内容数据、引用校验、章节树查询        | 仅依赖 core                                                  |
| geometry    | Möbius 变换、投影、曲线裁剪、镜头构图 | 仅依赖 core；所有镜头和视口参数显式传入                      |
| application | 阅读状态、命令、返回快照、过场推进    | 依赖 core / content / geometry；不访问 DOM、事件或浏览器时间 |
| rendering   | SVG 和正文更新                        | 读取状态、查询目录；生成命令描述，不执行导航                 |
| effects     | 背景场、独立 V24 动画                 | 接收镜头、时间、配置；不修改阅读路径                         |
| platform    | 浏览器输入适配、帧时钟                | 输入面向端口，时钟面向回调；不依赖应用实现                   |

数据流：浏览器事件 → Command → Field → FieldState → Scene / Ambient。

时间由一个 `requestAnimationFrame` 时钟注入。应用自身可以用测试中的虚拟时间推进；V24 不另开动画循环。模块销毁时取消帧时钟、监听器并清理创建的节点。

语义状态（章节身份、父子路径、引用目标）和表现状态（形态、镜头、折叠、滚动插值）分开。切换圆／线不重建内容树；跨枢保留各枢路径。返回快照包含路径、形态、镜头和查询；搜索结果由查询恢复，保存在阅读会话中，目录不保存可变查询结果。

内容模块只声明动作标识，不操作设置。应用层解释 `act:` 命令；渲染器只将引用转换为按钮，输入适配器将按钮点击翻译为命令。

## 独立修改

添加文章只需修改内容定义。修改投影或圆线模型只需修改 geometry。修改输入手势只需修改 platform/input。更换 DOM 渲染方式时可保留内容、几何和应用状态机。

加载内核保留原蓝图的 JavaScript 实现，作为局部兼容边界；只通过 `start / exit / update` 和两个回调通信。入口保留新版的 `window.__shuyra` 调试对象和章节、形态、主题 URL 参数，用于关键帧检查。正文构建保留在 `rendering/article.ts`，图标和示例由场景渲染器注入。局部标签的入退场由 `rendering/local-labels.ts` 以统一逻辑时间推进：保留旧标签身份直到退场结束，新组随后展开；动画期间不注册点击动作，稳定后恢复静态零 DOM 改动。

## 测试

`field.test.ts` 检查几何不变量、直线奇点两侧、递归提交、跨枢返回、重复引用、设置主题恢复和缩放锚点。

`scene.test.ts` 使用 DOM 模拟检查正文显隐、形态表达、真实链接按钮，以及背景和 V24 的有限路径与完整生命周期。它不能替代真实浏览器视觉和性能验收。

## 背景流场与镜头

`effects/flow-field.ts` 在世界坐标中定义平滑无散基础流和有限寿命的径向波扰动。`effects/streamlines.ts` 负责确定性种子和中点积分，`effects/ambient.ts` 只绘制路径、示踪点和阅读区域淡出。场采样在静止时每 400ms 更新，波扰动期间每 125ms 更新；镜头变换和示踪点由统一帧时钟推进。静态场景跳过 DOM 更新，时钟默认使用省电自适应档（交互最多 60 帧、静止阅读最多 24 帧），也可选择固定上限或跟随屏幕刷新率；页面隐藏时暂停。波扰动是视觉模型，不宣称物理能量守恒。

圆态滚动调用纯函数 `orbitCamera`：由当前镜头和新的朝向计算绕圆心的镜头位置，严格保持圆心投影，保留缩放比例。线态滚动保持镜头不动，章节沿轴移动。所有世界坐标统一按镜头倍率投影；曲线、标签、图标、正文、背景和描边同比例缩放。切换枢时，`frameFor` 以约 15px 的正文字号为目标确定默认倍率，并使用与正文相同的列宽规则安排水平位置和靠上阅读的落点。正文围绕局部阅读锚点缩放而不重新排版；拖动与滚轮按镜头倍率换算回局部坐标。顶部固定工具栏与左下角说明文字使用屏幕尺寸，不随镜头缩放；加载图形仍使用镜头倍率。聚焦缩放通过 Alt/Ctrl/Command + 滚轮、捏合和加减键触发；正文滚轮优先浮动长文，局部导航滚轮只移动标签带，其余普通滚轮继续阅读。

帧率选项由 `core/frame-rate.ts` 统一声明；应用层解释选项命令，时钟只接收更新频率。跟随屏幕档直接使用每次浏览器帧回调，不估算或硬编码屏幕 Hz。浏览器偏好存储由 `platform/preferences.ts` 处理，存储不可用时仍可在当前会话切换档位。
