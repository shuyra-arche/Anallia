# 演示路线

首页是可操作的导览，不以数学推导开场。用户可以按主线逐站体验，也可以从首页直接进入长文或背景设置。

| 入口 | 内容 | 主要操作 |
| --- | --- | --- |
| α₀ | 从这里开始 | 阅读操作提示，选择体验入口 |
| α₁ → α₂ | 圆周阅读与圆线形态 | 空白处滚动、方向键、抓握、点击当前标签 |
| β₀ → β₁ | 斜向线枢 | 沿导轨浏览，观察进入来向 |
| θ₀ | 从另一侧靠近 | 对比阅读展开侧与导轨方向 |
| α₄ / μ₃ | 长文 | 正文内滚动，选择和复制文字 |
| δ₀ | 主题与转场 | 比较同底色与异底色跳转、翻页和返回 |
| ⚙₆ | 星空、流场与关闭 | 选择背景并在刷新后保留 |

α₃ 的九标签序列和 λ₀ 的十二标签序列作为进阶演示保留。设置与搜索随时可用。原有章节标识和层级不变，已分享的 `?chapter=...` 链接继续有效。

站点使用 GitHub Actions 发布到 `/Anallia/`；源码、测试和构建脚本保存在同一仓库，发布产物不写回源码分支。
